# TableMate

Telegram bot for table reservations that shows only genuinely available slots, gives instant confirmations with a short code, supports reschedule/cancel, reminders, and an owner dashboard.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
